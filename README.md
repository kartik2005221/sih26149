# s0 (Sector Zero) — Unified Forensic Sanitization & Recovery Workstation

> **Smart India Hackathon (SIH) — Problem Statement 26149**  
> **Title:** Design and Development of an Integrated Secure Data Erasure and Advanced File Recovery Tool for Digital Forensics and Data Sanitization

---

**s0 (Sector Zero)** is an integrated, prototype forensic tool combining NIST SP 800-88 Rev. 1 compliant media sanitization, selective file/folder erasure with metadata scrubbing, structure-aware deleted file carving (FAT32), and append-only blockchain audit tracking with Ed25519 cryptographic certification.

---

## Key Capabilities

```
┌────────────────────────────────────────────────────────────────────────┐
│                        s0 Unified Platform                             │
├───────────────────┬───────────────────┬────────────────────────────────┤
│ 1. Drive Sanitizer│ 2. File Eraser    │ 3. File Carver & Recovery      │
│ - NIST 800-88     │ - In-place scrub  │ - FAT32 structure-aware        │
│ - Zero/Random pass│ - Attribute clean │ - 8 forensic signatures        │
│ - ATA/NVMe Purge  │ - CoW warnings    │ - Entropy confidence scoring   │
├───────────────────┴───────────────────┴────────────────────────────────┤
│ 4. Blockchain Audit Ledger: Continuous SHA-256 hash-chained logs       │
│ 5. Cryptographic Certification: Ed25519 signed Canonical JSON (RFC8785)│
│ 6. Web Dashboard: Local interactive browser interface (127.0.0.1:8000) │
└────────────────────────────────────────────────────────────────────────┘
```

- **Module 1: Drive Eraser (`s0 wipe`)**: Wipes whole block devices or raw disk images. Supports single/multi-pass zero or CSPRNG random overwriting (NIST Clear) and hardware-level ATA Secure Erase & NVMe Sanitize dispatch (NIST Purge). Includes pre/post-wipe sampled readback verification.
- **Module 2: File & Folder Eraser (`s0 erase`)**: Overwrites specific files and directory trees, scrubs filesystem attributes/permissions, flushes storage hardware write buffers (`fsync`), and detects Copy-on-Write (CoW) filesystems.
- **Module 3: Advanced File Carver (`s0 carve`)**: Structure-aware deleted file recovery for FAT32 (USB flash drives, SD cards) combined with header/footer magic byte carving for 8 major file types (PDF, JPEG, PNG, ZIP/DOCX, MP4, GIF, BMP, WAV) and Shannon entropy scoring.
- **Module 4: Blockchain Audit Ledger (`s0 audit`)**: Every operation is logged into an append-only, SHA-256 hash-chained SQLite ledger anchored by a Genesis block for non-repudiation.
- **Module 5: Cryptographic Certification & Verification (`s0 verify`)**: Generates tamper-proof Ed25519-signed certificates formatted in deterministic Canonical JSON (RFC 8785) and human-readable PDF reports.
- **Module 6: Web Dashboard (`s0 web`)**: Lightweight local FastAPI console providing visual telemetry, real-time logging, and one-click certificate downloads.

## Quick Start

### 1. Installation

```bash
# Clone the repository
git clone https://github.com/kartik2005221/sih26149.git
cd sih26149

# Create virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies and local modules
pip install -r requirements.txt
pip install -e core/python
pip install -e linux/cli
```

### 2. Basic Commands

```bash
# List block devices
s0 list

# Dry-run sanitization plan
s0 plan --target /path/to/disk.img

# Sanitize a drive or image
s0 wipe --target /path/to/disk.img --yes --pattern zero --out-dir ./output

# Securely erase specific files
s0 erase --targets sensitive.docx /tmp/confidential_dir/ --out-dir ./output

# Carve deleted files from FAT32 media or disk image
s0 carve --target /path/to/usb_evidence.raw --out-dir ./recovered

# Verify blockchain audit chain integrity
s0 audit verify

# Verify certificate offline
s0 verify output/certificate_<uuid>.json --key core/keys/demo_issuer_public.pem

# Launch local Web Dashboard
s0 web --port 8000
```
